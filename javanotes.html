1. What is Java?

Java is a high-level, object-oriented programming language. It is widely used for web applications, backend systems, enterprise applications, desktop applications and many other types of software.

Object Oriented

Java is based heavily on classes and objects.

Platform Independent

Java bytecode can run on different operating systems through the JVM.

Secure

Java provides various security features and runtime checks.

⚡ Powerful

Java supports multithreading, networking, collections and much more.

Important: Java follows the idea "Write Once, Run Anywhere" because compiled Java bytecode can run on systems that have a compatible JVM.

JDK

JDK stands for Java Development Kit. It provides tools needed to develop Java applications.

JRE

JRE stands for Java Runtime Environment. It provides the environment required to run Java applications.

JVM

JVM stands for Java Virtual Machine. It executes Java bytecode.

int[] numbers = {10, 20, 30, 40, 50}; for (int i = 0; i < numbers.length; i++) {

}

11. Object-Oriented Programming

OOP is one of the most important concepts in Java.

1. Encapsulation

Protect data by controlling access to it.

2. Inheritance

Allow one class to inherit from another class.

3. Polymorphism

One interface or method can have multiple forms.

4. Abstraction

Hide unnecessary implementation details.

Class and Object

 class Student {

String name;
 
int age;

void display() {

System.out.println(name); System.out.println(age);

}

public static void main(String[] args) {
Student s1 = new Student(); s1.name = "Rahul";
s1.age = 20;

s1.display();
}
}

Constructor

 class Student {

String name; int age;
Student(String name, int age) { this.name = name;
this.age = age;

}

}

Inheritance


 
class Animal {

void eat() { System.out.println("Animal eats");
}

}
class Dog extends Animal { void bark() {
System.out.println("Dog barks");
}

}

Method Overloading

 class Calculator {

int add(int a, int b) { return a + b;
}

int add(int a, int b, int c) { return a + b + c;
}

}

Method Overriding

 class Animal {

void sound() { System.out.println("Animal sound");
}
 
}
class Dog extends Animal { @Override
void sound() {
System.out.println("Bark");
}

}

Interface

 interface Vehicle {

void start();

}

class Car implements Vehicle { public void start() {
System.out.println("Car starts");

}

}

22. Garbage Collection

Java automatically manages memory using garbage collection. Objects that are no longer reachable can eventually have their memory reclaimed by the JVM.

You normally do not manually free Java objects like you commonly do with dynamically allocated memory in C.

25. Beginner Java Project

After learning the basics, try building a simple student marks program. 

 import java.util.Scanner;

class StudentMarks {

static void checkResult(int marks) { if (marks >= 50) {
System.out.println("Pass");

} else {

System.out.println("Fail");

}

}

public static void main(String[] args) { Scanner sc = new Scanner(System.in);
 
System.out.print("Enter student name: "); String name = sc.nextLine();

System.out.print("Enter marks: "); int marks = sc.nextInt();

System.out.println("Student: " + name); System.out.println("Marks: " + marks);

checkResult(marks); sc.close();
}
}
